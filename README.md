# 💜 LUNA CURVE
### *Fashion that fits your curves.*

Welcome to **Luna Curve**, a stylish plus-size women's fashion e-commerce website designed to celebrate curves, confidence, and individuality. The project focuses on making online fashion shopping accessible, enjoyable, and visually appealing for women looking for fashionable clothing in inclusive sizes.

Luna Curve combines a modern shopping experience with elegant visuals, carefully selected colours, and an easy-to-navigate interface.

---

## ✨ About the Project

Luna Curve is a front-end e-commerce project created to explore modern web design and interactive online shopping experiences. The website showcases plus-size fashion with a focus on affordability, inclusivity, and style.

The design uses a sophisticated colour palette featuring deep plum, black, burgundy, and emerald accents to create an elegant fashion-store aesthetic.

## 🎯 Project Objectives

- 👗 Promote inclusive fashion for plus-size women.
- 💜 Create an attractive, modern, and user-friendly shopping interface.
- 🛍️ Organise clothing into categories for easier browsing.
- 🔎 Provide interactive shopping features and product discovery.
- 📱 Explore responsive web design for different screen sizes.
- 🎨 Apply UI/UX principles to create a consistent brand identity.

## 🌟 Features

- **Fashion Homepage:** A stylish landing page introducing the Luna Curve brand.
- **Inclusive Fashion:** Product displays featuring plus-size clothing, with sizes ranging from XL to 5XL.
- **Product Browsing:** A visual catalogue for exploring fashion items.
- **Interactive Navigation:** Easy-to-use navigation and shopping controls.
- **Shopping Interface:** A front-end shopping experience designed around product discovery and cart interactions.
- **Modern Visual Design:** Elegant colours, fashion imagery, and polished layouts.
- **Responsive Design:** A design approach intended to support different screen sizes.

*Note: Features such as cart functionality and responsiveness depend on the implementation in the current version of the project.*
